# eds-skills

Skill library for Brad's Engineering Design System. See the `engineering-design-system` repo for the governing framework documents (`SKILL_FRAMEWORK.md` in particular defines the structure every skill here must follow).

Each skill lives in its own folder under `/skills/`:
- `skill.json` — metadata
- `main.py` — skill logic
- `README.md` — what it does, how to invoke it
- `test.py` — acceptance test
- `SKILL.md` — generated packaging file for Cowork installation
