# eds-skills

Skill library for the Engineering Design System. Rules for every repo (branching, merges, workflows, tickets, answer format) live once in the home repo's `CLAUDE.md`, https://github.com/bradcurtis-personal/engineering-design-system/blob/main/CLAUDE.md. Sessions start there; a session opened here directly reads it first, and treats that repo as its baseline rule set. `README.md` here describes the layout and the release pipeline.

## Layout
- `skills/<name>/`: one folder per skill, structured as `SKILL_FRAMEWORK.md` requires.
- `tooling/`: `package_skill.py` (the pipeline engine), `preflight.py` and their tests.
- `plugins/`, `.claude-plugin/`: generated by the release pipeline; don't edit by hand.
- `.github/workflows/`: `skill-pr-check.yml` and `skill-release.yml`.

## Tests
Python and `gh` run through WSL (see Ticket Workflow). Run a changed skill's `test.py` and its audit, and the `tooling/` tests locally; CI does not run those.

## Rules for this repo
- Any change inside a skill's folder needs a version bump and a README version-history line.
- The framework standards and `ACCOUNTS.md` live only in the `engineering-design-system` repo; read them there.
