# eds-skills

Skills repo for the Engineering Design System.

## Hard limits (always apply)
- Never commit to main. Branch from a freshly fetched origin/main.
- Merges stay with Brad. Open the PR, report the number and check status,
  then stop.
- Anything under .github/workflows/ needs Brad's diff review before pushing.
- Any change inside a skill's folder needs a version bump.

## Tickets
To work on or create any Jira ticket, read the Notion page "Ticket Workflow"
(Framework Docs) first and follow it. Repos and tools are in `ACCOUNTS.md`
in the `engineering-design-system` repo
(https://github.com/bradcurtis-personal/engineering-design-system/blob/main/ACCOUNTS.md).
The framework standards (`ENGINEERING_DESIGN_SYSTEM.md`, `AUTONOMY_RANKS.md`,
`SKILL_FRAMEWORK.md`, `INTERFACE_CONTRACTS.md`, `STACK.md`,
`DEFINITION_OF_DONE.md`, `WORKFLOW.md`, `PROJECTS.md`, `Skill Ideas/`) live
only in that repo (see its `README.md`); Notion pages with those names are
stubs that link to it. The Cowork Session Prompt, Ticket Workflow, Skills
Library and Learning live only in Notion.
If Notion is unreachable, say so and ask Brad rather than guessing.
