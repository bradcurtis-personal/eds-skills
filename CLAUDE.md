# eds-skills

Skills repo for the Engineering Design System.

## Hard limits (always apply)
- Never commit to main. Branch from a freshly fetched origin/main.
- Merges stay with Brad. Open the PR, report the number and check status,
  then stop.
- Anything under .github/workflows/ needs Brad's diff review before pushing.
- Any change inside a skill's folder needs a version bump.

## Tickets
To work on or create any Jira ticket, read the Notion page "Ticket Workflow"
(Framework Docs) first and follow it. Repos and tools are on "Accounts".
If Notion is unreachable, say so and ask Brad rather than guessing.
